# Разметка — инструкция для команды

Всё делается **локально** в Label Studio: http://localhost:8080. Логин и пароль лежат в `annotation/.ls_credentials`.
Кадры организаторов никуда не загружаем (FAQ 6).

Запуск сервера: `python scripts/label_studio.py start` (окно терминала не закрывать).

---

## Этап 1. «1. Зоны» — 42 кадра, ~20–30 минут на одного человека

На каждом кадре (один кадр на видео) отметить:

**Полигоны** (клавиша → клики по углам → Enter):

| Класс | Клавиша | Что обводить |
|---|---|---|
| `floor` | F | Видимый пол **внутри** кассы, до основания стен и стекла |
| `glass_wall` | G | Всю стеклянную стену **вместе с дверью**: здесь появляются отражения и люди за стеклом |
| `desk` | D | Столешницу рабочего стола |

**Прямоугольники:**

| Класс | Клавиша | Что обводить |
|---|---|---|
| `banknote_counter` | 1 | Счётчик банкнот (чёрный аппарат на столе) |
| `laptop` | 2 | Ноутбук |
| `safe_closed` / `safe_open` | 3 / 4 | Сейф (серый шкаф). Состояние — **как на этом кадре** |
| `door_closed` / `door_open` | 5 / 6 | Дверь кассы (створка в стеклянной стене) |

Черновые рамки ноутбука уже стоят: их нужно проверить и подвинуть. Закончили кадр → **Submit**.
После всех 42 кадров: `python scripts/label_studio.py export zones`.

## Этап 2. «2. Объекты» — ~600–900 кадров, делим на 2–3 человек

Этот этап готовлю я после экспорта зон. В черновике уже будут рамки счётчика, ноутбука, сейфа и двери
(скопированы с этапа 1) и рамки YOLO для телефона, сумок и стаканов.

**Что делать на каждом кадре:**
1. **Проверить черновые рамки**: подвинуть, удалить лишние, исправить класс (например, сумка инкассатора `collector_bag`, а не `personal_item`).
2. **Поправить состояние** сейфа и двери, если на этом кадре они открыты или закрыты иначе, чем в черновике.
3. **Дорисовать то, чего нет в черновике:**

| Класс | Клавиша | Что это |
|---|---|---|
| `cash` | 1 | Деньги: купюра, веер, пачка. В руке, на столе, в лотке счётчика — везде |
| `id_card` | 2 | Удостоверение личности / документ клиента |
| `phone` | 3 | Мобильный телефон (в руке или на столе) |
| `collector_bag` | Q | Сумка инкассатора (зелёная, с пломбой) |
| `personal_item` | W | Личные вещи кассира: сумка, куртка, кошелёк |
| `food_drink` | E | Еда, стакан, бутылка |

4. **Submit.** Если на кадре ничего нет, всё равно нажать Submit: пустой кадр тоже полезный пример.

## Правила (важно для качества модели)

- **Рамка плотная**, по краям объекта, без лишнего фона.
- **Частично видимый** объект (рука закрывает половину пачки) — размечать видимую часть.
- **Отражения в стекле НЕ размечать.** Объекты за стеклом размечать, только если это реальный предмет за стеклом.
- **Мелкое тоже размечать**: одна купюра — `cash`. Если совсем не разобрать, лучше пропустить, чем угадывать.
- **Несколько купюр рядом** = одна рамка `cash`. Пачки в разных местах = отдельные рамки.
- **Сейф открыт** = дверца открыта хоть немного. **Дверь открыта** = створка не в закрытом положении.
- **Лица не трогаем**: людей и лица не размечаем вообще. Людей модель уже знает.
- Если сомневаетесь в классе, пропустите объект и запишите имя кадра в чат.
- Масштаб: колесо мыши, перетаскивание с пробелом. Удалить рамку: выделить → Backspace.

## Как делить работу

В проекте «Объекты» откройте **Data Manager → фильтр по полю `video`**:
- человек 1: X-1 … X-17;
- человек 2: X-18 … X-33;
- человек 3: X-34 … X-48.

Кадры с `near_violation = true` (рядом с нарушением) размечайте в первую очередь: они важнее всего.

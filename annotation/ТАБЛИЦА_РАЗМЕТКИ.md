# Таблица разметки для ИИ

Проект в Label Studio: **«2. Объекты (детектор)»** — http://localhost:8080
Инструмент: прямоугольник. Выбрать класс клавишей → протянуть рамку мышью → **Submit** (Ctrl/⌘+Enter).

## Классы

| Клавиша | Класс | Что это | Как рисовать рамку | Не путать / не размечать |
|---|---|---|---|---|
| **1** | `cash` | Деньги: купюра, веер, пачка, стопка | Вокруг всех купюр, лежащих вместе. Пачка в руке — только купюры, без руки | Белые листы бумаги, чеки, документы |
| **2** | `id_card` | Удостоверение личности, паспорт, банковская карта клиента | Плотно по краям карточки, даже если её держат пальцами | Телефон (толще, с экраном) |
| **3** | `phone` | Мобильный телефон: в руке, у уха, на столе | По корпусу телефона | Рабочий стационарный телефон на столе (не размечать), калькулятор |
| **4** | `banknote_counter` | Счётчик банкнот: чёрный аппарат, в который кладут деньги | Весь корпус аппарата вместе с лотками | Принтер, ноутбук |
| **5** | `laptop` | Ноутбук / монитор кассира | Весь ноутбук, открытый или закрытый | — |
| **6** | `safe_closed` | Сейф (серый металлический шкаф), дверца **закрыта** | Весь корпус сейфа | Белая тумба под сейфом — не входит |
| **7** | `safe_open` | Сейф, дверца **открыта хоть немного** | Корпус + открытая дверца целиком | — |
| **8** | `door_closed` | Дверь кассы (створка в стеклянной стене) **закрыта** | Вся створка от пола до верха | Неподвижные стеклянные панели рядом |
| **9** | `door_open` | Дверь кассы **открыта** (не в закрытом положении) | Вся створка в её текущем положении | — |
| **Q** | `collector_bag` | Сумка / мешок инкассатора (зелёная, с пломбой) | По сумке, в руках или на столе | Личная сумка кассира → `personal_item` |
| **W** | `personal_item` | Личные вещи: сумка, рюкзак, куртка, кошелёк | По вещи целиком | Сумка инкассатора → `collector_bag` |
| **E** | `food_drink` | Еда, стакан, кружка, бутылка | По предмету | — |

## Чего НЕ размечать

| Что | Почему |
|---|---|
| Людей, лица, руки | Людей модель уже знает, руки берём из модели позы. Лица трогать нельзя по правилам |
| **Отражения в стекле** | Иначе ИИ научится видеть предметы там, где их нет |
| Объекты, которые невозможно разобрать (размытые, 2–3 пикселя) | Лучше пропустить, чем угадать неправильно |

## Правила

1. **Рамка плотная**: края рамки по краям объекта, без лишнего фона.
2. **Перекрытый объект** (рука закрывает часть пачки) → рамка по **видимой** части.
3. **Каждый объект отдельно**: две пачки в разных местах = две рамки. Купюры веером в одной руке = одна рамка.
4. **Черновые рамки** (они уже стоят на кадрах) проверить: подвинуть, удалить лишнюю (Backspace), поменять класс (выделить рамку → нажать клавишу класса).
5. **Сейф и дверь**: на каждом кадре проверить состояние открыт / закрыт. Именно это ИИ будет использовать для нарушений.
6. **Пустой кадр** (нет ни одного объекта из списка) → всё равно **Submit**: это тоже полезный пример.
7. **Сомневаешься** → лучше пропусти объект (кнопка **Skip** у кадра) и напиши номер кадра в чат.

## Как это потом использует ИИ

| Что размечаем | Какие нарушения по этому ловим |
|---|---|
| `cash` + счётчик + положение клиента | пересчёт не на виду у клиента, деньги оставлены без присмотра |
| `safe_open` / `safe_closed` | сейф оставлен открытым, кассир ушёл при открытом сейфе |
| `door_open` / `door_closed` | дверь кассы не закрыта, вход постороннего |
| `phone` | телефон в кассе |
| `collector_bag` | приём сумки инкассатора без проверки |
| `personal_item`, `food_drink` | личные вещи и еда на рабочем месте |
| `id_card` | проверка документа клиента (есть / нет) |
| `laptop` | ориентир «рабочая сторона стола»: так ИИ отличает кассира от клиента |

## Как делить работу

Data Manager → **Filters** → `video` → выбрать свои ролики:

| Кто | Ролики |
|---|---|
| Человек 1 | X-1 … X-17 |
| Человек 2 | X-18 … X-33 |
| Человек 3 | X-34 … X-48 |

Сначала размечайте кадры с `near_violation = true`: они рядом с нарушениями и важнее всего.
Темп с черновыми рамками примерно 10–20 секунд на кадр.

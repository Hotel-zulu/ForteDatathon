# Правила нарушений

Источник списка: таблица команды `configs/violations_table.csv`; нормы и цитаты: `configs/regulations.yaml`
(только они попадают в ответ, ничего не придумывается). Код правил: `src/detectors/rules.py`,
сцена (кто в комнате, неподвижные объекты): `src/detectors/scene.py`.

## Как работает

1. Модель на каждом кадре (10 к/с) находит деньги, удостоверение, счётчик, ноутбук, сейф (открыт/закрыт),
   дверь, сумки и людей (с трекингом). Плюс два пиксельных признака: светится ли экран ноутбука и
   насколько участок двери отличается от закрытого состояния.
2. «Человек в комнате»: низ его рамки не выше основания двери/стекла. Те, кто за стеклом, и отражения
   стоят «дальше» стекла, поэтому отсекаются без ручной разметки зон (на новом ракурсе её не будет).
3. Правила работают по таймлайну:

| Правило | Что видит | Тип (regulations.yaml) | Ролики |
|---|---|---|---|
| Уход кассира | комната опустела; на столе остались деньги | `cash_left_unsecured` (№231 п.20) | X-26 |
| | … сумка инкассатора | `leaving_workplace` (№231 п.22) | X-15 |
| | … светится рабочая программа на экране | `workstation_unlocked` (АРРФР №53 п.71 подп.9) | X-11, X-28 |
| | … сейф открыт | `safe_left_open` (№231 п.20) | |
| Следующий клиент | подошёл новый клиент, деньги прошлой операции лежат на столе | `cash_left_unsecured` | X-4, X-38, X-47 |
| Сейф открыт | ≥6 c и не закрыт до конца записи (или ≥12 c) | `safe_left_open` | X-20 |
| Дверь открыта | участок двери ≥6 c отличается от закрытого | `door_left_open` (№14 п.16, п.8) | X-32, X-33 (+X-30) |

Таймкод ухода: между «встал с места» и «вышел из комнаты» (45% пути). Сам уход — не нарушение
(в X-12, X-23, X-25, X-27, X-29 кассир уходит правильно: деньги убраны, экран заблокирован).

## Замечания по данным

- **X-47 — тот же файл, что X-4; X-48 — тот же, что X-5** (md5 совпадает). В разметке организаторов
  у X-4 таймкод 57 c, у X-47 — 68 c на одном и том же видео.
- X-46: на видео кассир пьёт из стакана/ест на рабочем месте; в таблице команды — «нет комплексной проверки
  подлинности». Стоит пересмотреть.

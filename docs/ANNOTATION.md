# Разметка: что происходит в каждом ролике

Первая задача команды: посмотреть ВСЕ 42 ролика и заполнить таблицу. Отсюда получаются типы нарушений,
правила для детекторов и обоснования (критерии 3 и 4).

Кадры вокруг размеченных моментов: `python scripts/extract_frames.py --around 3 --fps 10`
→ `workdir/frames/<видео>/`. Сами видео удобно смотреть в QuickTime/VLC с покадровой перемоткой.

Сводка разметки организаторов: 42 видео, 22 с нарушением, 20 без нарушения.
Имена X-1, X-2 написаны латиницей, остальные кириллической «Х»: `src/labels.py` это нормализует.

## На что смотреть

- **Пары «нарушение / без нарушения»**: часто это одна сцена, сыгранная правильно и неправильно. Разница между ними и есть признак, который надо детектировать.
- **Нарушения по бездействию** (не проверил, не показал, не пересчитал): какой таймкод ставить, решает команда (FAQ 10). Зафиксируйте единое правило, например «момент, когда действие должно было произойти».
- **Роли**: как отличить кассира, клиента и инкассатора без распознавания лиц (зона, одежда, сумка, сторона стойки)?
- **Нарушения, которые по видео НЕ установить** (сверка, проводки): их не детектируем (п. 7 ТЗ). Выпишите их в docs/LIMITATIONS при сдаче.

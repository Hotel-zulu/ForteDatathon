# Разметка: что происходит в роликах

> Черновик составлен по раскадровкам ±4 c вокруг меток организаторов (`workdir/review/index.html`).
> **Уверенность**: ✅ видно однозначно · 🟡 вероятно · ❓ неясно, команде пересмотреть видео целиком.
> Колонку «Тип» сверить и исправить, потом включать типы в `configs/regulations.yaml`.

## Общее о сцене

- Комната кассы, камера сверху из угла, **вертикальное видео 1080×1920** (кадр узкий и высокий).
- В кадре: стол с счётной машинкой, ноутбуком, телефоном; **сейф** (серый шкаф справа/сзади); стеклянная стена с **дверью** слева.
- Кассир — одна девушка (в розовом или белом), сидит/встаёт. Клиент садится **с другой стороны стола** (тоже внутри комнаты).
- Инкассатор приносит **зелёную сумку** (X-17).
- В части роликов меняется ракурс/комната (X-11 — другая точка съёмки и выключенный свет) и расстановка мебели.
- Нарушения короткие (секунды), метка ставится примерно на момент действия.

**Вывод для архитектуры**: почти все нарушения определяются через **людей + зоны + несколько предметов**:
кассир (в зоне стола / вне / у двери), клиент, посторонний, **сейф открыт/закрыт**, **дверь открыта/закрыта**,
телефон, сумка/куртка, еда/стакан, деньги в руках. COCO-модель RT-DETR даёт людей, телефон, сумки, стакан;
**сейф, дверь и деньги** — дообучить на кадрах из датасета (или классификатор состояния зоны по кропу).

## Что сделать команде

1. Пересмотреть ❓ и 🟡 **целиком** (особенно X-4, X-13, X-38, X-44), сравнить с похожими роликами без нарушения.
2. Ролики без нарушения пока не размечены: найти пары («та же сцена, сыграно правильно»). Так проще увидеть разницу.
3. Для каждого типа сверить пункт на adilet.zan.kz → `configs/regulations.yaml` (`verified: true`, `enabled: true`).
4. Тип 8 (еда): найти норматив или внести в ограничения. Выдумывать ссылку нельзя (критерий 4).
5. Таймкод «по бездействию» (дверь, сейф): договориться о правиле, например момент, когда кассир отошёл от открытого сейфа.
